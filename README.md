# 拾音成曲：交互音乐工作站
本作品面向乐谱阅读、单音练习与音乐创作，设计了一套基于安路EG4S20BG256 FPGA的“拾音成曲：交互音乐工作站”。系统通过SPI读取TF卡FAT32文件系统中的640×480、24位非压缩BMP图像，使用SDRAM双帧缓冲和HDMI实时显示；音频部分支持48 kHz HDMI输出，提供钢琴PCM、方波以及小提琴采样音色与四轨音序播放。作品的核心创新是将SPH0645 I²S麦克风采集的声音，经直流分量估计、能量门控和AMDF单音音高分析，转化为包含音高、起止位置及持续时间的音符事件，自动写入选定音轨，并在停止演奏后回放验证。图片界面可叠加迷你音轨编辑器，实现“看乐谱—演奏—记录—回放”的连续操作；同时利用Goertzel算法计算8个真实频率分量进行麦克风频谱可视化，并提供图片缩放、亮度调节和动态中文操作提示。在小规模FPGA的LUT、MSlice和片上RAM约束下，设计采用音频计算时分复用、紧凑状态机、共享点阵字库及存储空间分区。该系统的“记谱”指钢琴卷帘式音符事件记录，并非由声音直接生成标准五线谱。本文记录系统架构、接口设计、关键算法、资源结果与实机验证项目，为后续持久化存储及复音识别扩展提供基础。
